# MODO v0.2 Implementation Plan

> **For agentic workers:** 실행은 메인 세션이 직접(inline) 한다. 사용자 선호(큰 결정만 묻고 끝까지 진행)에 따라 단계 사이에 승인을 기다리지 않는다.
> 규모(12단계)상 이 문서에는 파일 구조·작업·인터페이스 이름·검증 기준만 적고, 코드는 저장소에 바로 쓴다. 체크박스로 진행 상황을 기록한다.
> 설계: [`docs/specs/2026-11-11-modo-v2-design.md`](../specs/2026-11-11-modo-v2-design.md)

**Goal:** TeamUp v0.1을 MODO v0.2로 개편 — 루트/프로젝트 2단 구조, 프로젝트별 화면 모드 4종, 채팅·파일·회의 시간 조율·회의록(STT·AI)·태그 초대.

**Architecture:** Activity + XML + ViewBinding 유지. 화면 조각은 `Section`(View 컨트롤러 클래스)으로 만들어 모드별 셸(ProjectActivity)이 조합한다. 데이터는 Firestore 실시간 리스너 → `LiveData<AppData>` 하나로 모으고(채팅 메시지만 방별 리스너), 파일은 Supabase Storage REST, AI는 Firebase AI Logic.

**Tech Stack:** Kotlin 2.4.21, AGP 9.3.3, compile/target 37, minSdk 26, Material 1.14.0, Firebase BoM 35.1.0(auth, firestore, ai), Credential Manager(Google 로그인), Supabase Storage REST(HttpURLConnection), SpeechRecognizer.

## Global Constraints

- 패키지·applicationId `com.modo.app`, 앱 이름 `MODO`, versionName `0.2.0`, versionCode 2.
- Activity 기반, Fragment·Compose 사용 안 함. 목록은 LinearLayout에 inflate (채팅도 같은 방식, 최근 150개 + 더 보기).
- 화면 문자열은 전부 `values/`(ko) + `values-en/`. 기능별 문자열 파일 분리 가능(`strings_chat.xml` 등).
- 색은 기존 토큰(`@color/primary`, `surface`, `text_*` …)만 사용. 다크 기본, 라이트 지원.
- Firestore 필드명·컬렉션은 설계 §4 그대로. enum은 `name` 문자열로 저장. 기존 필드·상태 값 변경 금지(v0.1 호환).
- 비밀 값(Supabase PAT, DB 비밀번호)은 저장소에 넣지 않는다. Supabase anon 키·URL은 공개 전제라 `BuildConfig`/리소스로 커밋 가능.
- 커밋·푸시는 사용자 요청이 있을 때만.
- 빌드: `JAVA_HOME`=Android Studio JBR, `GRADLE_USER_HOME=D:\Android\.gradle`, 에뮬레이터 `TeamUp_API36`.

## Key Interfaces (단계 사이에 이름을 맞추기 위한 목록)

```kotlin
enum class ProjectMode { TODAY, PROGRESS, WORKSPACE, CHAT }          // projects.mode
enum class TaskCategory { TODO, IN_PROGRESS, OVERDUE, DONE }         // TaskRules.category(task, today)
object Availability { const val SLOTS = 48; fun isFree(week: LongArray, day: Int /*1..7*/, slot: Int): Boolean;
                      fun set(week: LongArray, day: Int, slot: Int, free: Boolean): LongArray; fun empty(): LongArray }
data class Slot(val day: Int, val startSlot: Int, val lengthSlots: Int)
data class Recommendation(val slot: Slot, val available: List<String>, val unavailable: List<String>, val total: Int)
object MeetingFinder { fun recommend(members: List<Pair<String, LongArray>>, lengthSlots: Int, top: Int = 3): List<Recommendation> }
object UserTag { fun generate(random: Random): String; fun handleKey(name: String, tag: String): String;
                 fun parseQuery(raw: String): Query /* Handle(name, tag) | Email(email) | Invalid */ }
object ChatRepository { fun roomIdForProject(pid: String) = "p_$pid"; fun directRoomId(a: String, b: String): String }
interface Section { val root: View; fun render(data: AppData) }
```
