# 팀 프로젝트 관리 앱 주요 아이디어

팀 프로젝트를 진행할 때 팀원들이 각자 맡은 업무와 전체 진행 상황을 쉽게 확인하고 관리할 수 있도록 하는 앱이다. 프로젝트 생성부터 업무 분담, 일정 관리, 진행률 확인까지 한 곳에서 관리하는 것을 목표로 한다.

1. 메인 대시보드
- 현재 진행 중인 프로젝트 목록 표시
- 전체 업무 개수와 완료된 업무 개수 표시
- 프로젝트 전체 진행률을 그래프나 퍼센트로 표시
- 마감일이 가까운 업무를 메인 화면에 표시
- 최근 추가되거나 수정된 업무 확인

2. 프로젝트 관리
- 프로젝트 생성 및 삭제
- 프로젝트명, 설명, 시작일, 종료일 설정
- 프로젝트별 진행 상황 확인
- 여러 프로젝트를 구분하여 관리

3. 팀원 관리
- 팀원 추가 및 삭제
- 팀원 이름과 역할 설정
- 팀원별 담당 업무 확인
- 각 팀원의 업무 완료 개수와 진행률 표시

4. 업무 관리
- 새로운 업무 추가 및 수정·삭제
- 업무 제목과 상세 설명 입력
- 업무 담당자 지정
- 업무별 마감일 설정
- 업무 우선순위 설정(높음, 보통, 낮음)
- 업무 진행 상태 설정(예정, 진행 중, 완료)
- 체크박스를 이용한 업무 완료 처리

5. 일정 및 마감일 관리
- 업무별 마감일 확인
- 마감일이 임박한 업무 별도 표시
- 프로젝트 시작일과 종료일 확인
- 일정이 지난 업무와 완료되지 않은 업무 구분

6. 진행률 및 통계 확인
- 프로젝트 전체 업무 완료율 표시
- 팀원별 담당 업무 개수 표시
- 팀원별 완료 및 미완료 업무 확인
- 업무 상태별 개수 확인
- 프로젝트 진행 상황을 시각적으로 표시

7. - 프로젝트별 색상이나 아이콘 설정
- 우선순위에 따라 업무 색상 구분
- 직관적인 버튼과 간단한 화면 구성
- 화면 크기와 방향에 맞는 UI 구성
- 한국어 문자열 및 앱 테마 통일
