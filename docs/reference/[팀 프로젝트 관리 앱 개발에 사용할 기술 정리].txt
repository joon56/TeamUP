**[팀 프로젝트 관리 앱 개발에 사용할 기술 정리]**

팀 프로젝트 관리 앱을 개발할 때 수업 교안에서 배운 기술을 최대한 활용하고자 합니다.

 1. Kotlin 기본 문법 (3주차, 4주차)
- 변수와 자료형 (`val`, `var`)
- 함수 (`fun`)
- 조건문 (`if`, `when`)
- 반복문 (`for`, `while`)
- 컬렉션 (`List`, `MutableList`)
- 컬렉션 반복 및 인덱스 활용 (`indices`, `withIndex()`)
- 널 허용 타입 (`?`)
- `lateinit`, `lazy`

적용 기능
- 팀원 및 프로젝트 정보 저장
- 할 일 목록 추가·삭제·수정
- 업무 상태(예정, 진행 중, 완료)에 따른 화면 표시
- 마감일에 따른 상태 구분
- 팀원별 업무 목록 및 완료 개수 계산

 2. Android 화면 구성 및 위젯 (5주차)
- Activity와 View 구조
- XML을 이용한 화면 구성
- TextView: 프로젝트명, 업무명, 진행률 표시
- EditText: 프로젝트명, 업무 내용 입력
- Button: 추가, 수정, 삭제 기능
- ImageView: 팀원 프로필 및 아이콘 표시
- CheckBox: 업무 완료 여부 표시
- RadioButton / RadioGroup: 업무 우선순위 선택
- ViewBinding: XML 화면 요소와 Kotlin 코드 연결

 3. 레이아웃 (6주차)
- LinearLayout: 팀원 목록 및 업무 목록 배치
- RelativeLayout: 업무 카드 내부 요소 배치
- FrameLayout: 진행률 표시 및 화면 요소 겹쳐 배치
- GridLayout: 메인 화면의 통계 정보 배치
- ConstraintLayout: 메인 화면 및 업무 상세 화면 구성

 4. 사용자 이벤트 처리 (7주차)
- 클릭 이벤트: 업무 추가, 수정, 삭제 및 화면 이동
- 터치 이벤트: 화면 요소 터치 처리
- 키 이벤트: 키보드 입력 관련 처리
- 뒤로 가기 이벤트: 이전 화면으로 이동

적용 기능
- 버튼을 눌러 업무 추가 및 삭제
- 체크박스를 눌러 업무 완료 처리
- 팀원이나 업무 항목을 눌러 상세 화면 이동
- 뒤로 가기를 통한 화면 전환

5. 리소스 활용 (2주차, 9주차)
- drawable: 화면에 사용할 이미지 및 아이콘
- mipmap: 앱 실행 아이콘
- values/strings: 화면에 표시할 문자열
- values/colors: 앱 색상
- values/dimens: 여백 및 크기
- values/styles: 화면 스타일
- fonts: 글꼴 적용
- 리소스 조건 설정: 화면 방향 및 언어 등에 따른 리소스 구분

적용 기능
- 앱 전체 색상과 글꼴 통일
- 버튼 및 아이콘 디자인
- 화면 크기나 방향에 따른 UI 조정
- 한국어 및 영어 문자열 리소스 분리

 6. 최종 구현 기능
1. 프로젝트 생성 및 관리
2. 팀원 추가 및 관리
3. 업무 추가·수정·삭제
4. 업무 담당자 지정
5. 업무 우선순위 및 진행 상태 설정
6. 마감일 표시
7. 프로젝트 전체 진행률 표시
8. 팀원별 업무 완료 현황 표시
